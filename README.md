# 소비 정리

카드 승인 문자를 통째로 붙여넣으면 결제 내역으로 정리해 주는 개인 가계부.
프론트는 빌드 도구·프레임워크 없는 순수 HTML/CSS/JS, 뒤에 **Node.js(Express) + SQLite** 서버가
붙어 있어서 집 안 다른 기기(휴대폰, 다른 PC)에서도 같은 데이터를 본다.

## 실행 (서버를 띄울 컴퓨터에서)

1. [Node.js](https://nodejs.org) 설치(LTS 버전이면 충분).
2. 이 폴더에서:
   ```
   npm install
   npm start
   ```
3. 콘솔에 뜨는 주소로 접속.
   - 서버를 띄운 그 컴퓨터에서는 `http://localhost:3000`.
   - 같은 집 네트워크의 다른 기기(휴대폰 등)에서는 서버 컴퓨터의 LAN IP로,
     예를 들어 `http://192.168.0.10:3000`. 서버 컴퓨터의 LAN IP는:
     - Windows: `ipconfig` 실행 → "IPv4 주소".
     - macOS: `ipconfig getifaddr en0` (Wi-Fi 기준).
   - Windows에서 처음 실행하면 **Windows Defender 방화벽 알림**이 뜬다. "개인 네트워크"에
     접근 허용을 눌러야 다른 기기에서 접속된다.
4. 서버를 계속 켜 두려면(터미널을 닫아도 유지) `npm install -g pm2` 후 `pm2 start server.js --name spending`으로
   백그라운드 실행하거나, 그냥 서버용 컴퓨터에서 터미널 창을 열어 둔 채로 사용해도 된다.

기본 포트는 3000번이며, `PORT=8080 npm start`처럼 환경변수로 바꿀 수 있다.

### 예전 localStorage 데이터 옮기기

브라우저에만 저장돼 있던 예전 버전을 쓰고 있었다면: 그 브라우저에서 **CSV 내보내기**로 파일을
받은 뒤, 서버 컴퓨터로 옮겨서

```
node migrate-csv.js 소비내역_전체기간.csv
```

를 한 번 실행하면 DB(`spending.db`)에 그대로 들어간다(가맹점·카드는 CSV의 `설명` 칸
`가맹점 (카드)`에서 다시 분리해 넣는다). 서버가 켜져 있어도, 꺼져 있어도 상관없이 실행 가능하다.

## 쓰는 법

1. 브라우저에서 서버 주소로 접속한다(위 실행 섹션 참고).
2. 문자 앱에서 승인 문자를 여러 건 복사해 붙여넣고 **정리하기**(⌘/Ctrl+Enter)를 누른다.
   스프레드시트에 적어둔 내역은 상단 **표로 추가** 버튼을 눌러 뜨는 창에 탭 구분으로 붙여넣는다.
   한두 건뿐인 지출은 **직접 입력**으로 넣는다.
3. 분류가 어긋난 항목은 표에서 드롭다운으로 바꾼다. 같은 가맹점은 다음부터 그 분류로 자동 배정된다.
   일시·가맹점·카드·금액도 표에서 해당 칸을 누르면 바로 고칠 수 있다.

## 기능

- **파싱** — 카드사마다 줄바꿈 위치가 달라(현대카드는 항목마다 줄바꿈, 신한카드는 한 줄),
  줄 단위가 아니라 `헤더 → 금액 → 일시 → 가맹점 → 누적` 순서를 기준으로 텍스트 위치에서 읽어낸다.
  덕분에 두 형식을 섞어 붙여넣어도 카드사를 고를 필요가 없다.
  `(일시불)` `( 3개월)` 같은 할부 표기, `김*찬`/`김*찬님` 이름, `누적…원`, `정상승인 되었습니다` 따위는 걷어낸다.
  `승인취소` 문자는 음수로 잡힌다. 연도가 없는 `08/09`는 오늘 기준으로 추정한다(30일 이상 미래면 작년).
- **날짜 없는 문자** — 관리비·통신요금 자동이체처럼 일시가 없는 문자도 금액과 항목은 살려서 담고,
  표 맨 위에 **날짜 입력**으로 표시한다. 그 버튼을 누르면 그 자리에서 일시를 채울 수 있다.
  (날짜가 없는 동안에는 총액·분류별 집계에는 들어가고, 일별 차트와 월 필터에서는 빠진다.)
- **표에서 바로 수정** — 일시·가맹점·카드·분류·금액 모두 표의 해당 칸을 누르면 그 자리에서 고칠 수
  있다. 가맹점·금액은 입력창으로, 카드는 **지출 설정**에 등록한 목록에서 고르는 드롭다운으로 바뀐다.
  `Enter`로 확정, `Esc`로 취소한다.
- **표로 추가** — 상단 버튼을 누르면 뜨는 창에 엑셀·시트에서 복사한 탭 구분 표를 그대로 붙여넣는다.
  한 줄은 `날짜(선택) → 금액 → 가맹점 → 분류` 순서이며, 날짜 칸이 비어 있으면 바로 위 줄의 날짜를
  그대로 쓴다(날짜 칸이 병합된 표를 복사해도 그대로 들어맞는다). 분류 칸이 비어 있거나 목록에 없는
  값이면 가맹점명으로 자동 분류한다. 직접 입력과 마찬가지로 겹쳐도 그대로 담긴다.
- **직접 입력** — 날짜·시각·가맹점·금액·분류를 직접 넣어 한 건씩 추가한다. 분류를 `자동 분류`로 두면
  가맹점명에서 규칙대로 배정된다. 환불은 금액을 음수로 넣으면 된다.
- **중복 방지** — 일시·금액·가맹점이 모두 같으면 다시 붙여넣어도 한 건으로 남는다. 전체를 통째로 다시
  붙여넣어도 안전하다. 단 **같은 분에 같은 금액을 두 번 결제한 경우**는 문자의 `누적…원`이 서로 다르므로
  둘 다 남긴다(누적을 함께 비교한다). 직접 입력·표 추가는 사용자가 의도한 것으로 보고 겹쳐도 그대로 담는다.
  날짜가 없는 문자끼리는 금액·가맹점이 같으면 구분할 단서가 없어 한 건으로 합쳐지므로,
  매달 같은 금액이 나가는 자동이체라면 표에서 날짜를 채운 뒤 다음 달 문자를 넣으면 된다.
- **자동 분류** — 식재료 / 건강식품 / 기호식품 / 주거 / 교통 / 개인 / 쇼핑 / 여행 / 보험,곗돈 /
  전화·인터넷·iCloud / 육아(교육·생필품·간식) / 건강/의료 / 외식 / 배달 / 생활가전 / 생필품 /
  경조사 / 선물 / 회사점심 / 기타.
  규칙은 `public/app.js`의 `CATEGORY_RULES`에 있다. 손으로 고친 분류는 가맹점명 기준으로 학습된다.
- **카드 구분** — 문자에서 카드사(`현대카드 M`, `신한카드(8709)` 등)를 뽑아 내역마다 함께 저장한다.
  **카드별 지출** 막대로 카드마다 합산 금액을 보고, 상단 드롭다운으로 특정 카드만 골라 볼 수 있다
  (기간 필터와 함께 걸린다). 카드가 하나뿐이면 카드별 막대는 접힌다.
- **지출 설정** — 상단 **지출 설정** 버튼을 누르면 뜨는 창에서 쓰는 결제 수단(카드 이름은 물론
  `현금`도 그냥 이름으로 등록하면 된다)을 미리 등록해 두면, **직접 입력**의 카드 드롭다운과 표에서
  카드 칸을 고칠 때 그 목록 중 골라 넣을 수 있다. 뭘로 냈는지 모르면 기본값인 `카드 미상`을 그대로
  두면 된다. 등록한 목록은 `전체 삭제`를 눌러도 남는다.
- **요약** — 총 지출, 건수, 하루 평균, 최다 지출 분류. 분류별 가로 막대와 일별 세로 막대(호버 시 툴팁).
- **기간 필터** — 월 단위로 좁혀 볼 수 있다.
- **CSV 내보내기** — 현재 보고 있는 기간의 내역을 엑셀에서 바로 열리는 UTF-8 BOM CSV로 저장한다.
  컬럼은 `날짜`(시각 제외) · `금액` · `설명`(가맹점 + 카드) · `카테고리` 순.

## 데이터 보관

모든 내역은 서버 컴퓨터의 `spending.db`(SQLite, 파일 하나) 에 저장된다. 브라우저는 그때그때
서버에 물어보고 받아 올 뿐이라, 같은 서버에 접속하는 모든 기기가 같은 내역을 본다.
**전체 삭제**를 누르면 서버 DB에서 지워진다(되돌릴 수 없음). 백업은 `spending.db` 파일 하나만
복사해 두면 된다.

## 파일

| 파일 | 역할 |
|---|---|
| `server.js` | Express 서버 — 정적 파일 서빙 + `/api/*` |
| `db.js` | SQLite 연결·스키마 |
| `migrate-csv.js` | 예전 CSV 내보내기 파일을 DB로 가져오는 1회성 스크립트 |
| `public/index.html` | 화면 구조 |
| `public/styles.css` | 스타일 (라이트/다크 자동) |
| `public/app.js` | 파싱 · 분류 · 렌더 · 서버 API 호출 |
| `spending.db` | 실제 데이터(SQLite). git에는 올리지 않음(`.gitignore`) |
